# 📝 NoteFlow - MERN Notes Application

## 📌 Project Overview

NoteFlow is a full-stack MERN based note management application that allows users to create, store, search, and organize their notes through an interactive dashboard. The main goal of this project is to build a complete full-stack application where the frontend, backend, and database work together seamlessly.

The application provides a simple and efficient way to manage notes with a responsive user interface. It demonstrates real-world MERN stack development by integrating React with Express APIs and MongoDB database operations.

---

## ⚙️ How It Works

The frontend application is developed using React.js, which manages the user interface and application state. User actions like creating and viewing notes are handled through API requests to the Express.js backend.

The backend provides RESTful APIs that communicate with MongoDB using Mongoose. All notes data is stored and retrieved dynamically from the database, providing a complete end-to-end full-stack experience.

---

## 🚀 Key Features

- Create and save notes with title and content
- Fetch notes from MongoDB database
- Search notes for quick access
- Favourite important notes
- Delete and manage notes
- Responsive dashboard interface
- REST API based frontend-backend communication
- Dynamic data rendering using React hooks

---

## 🛠️ Tech Stack

**Frontend:** React.js, JavaScript, HTML5, CSS3, Vite  

**Backend:** Node.js, Express.js, MongoDB, Mongoose  

**Tools:** Git, GitHub, VS Code, Thunder Client, MongoDB Atlas

---

## 🔗 API Integration

The application uses REST APIs for communication between frontend and backend.

Implemented APIs:

- `GET /api/notes` - Fetch all notes
- `POST /api/notes` - Create a new note

The APIs enable smooth data exchange between React components and MongoDB database.
