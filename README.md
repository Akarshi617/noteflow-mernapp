# 📝 NoteFlow - MERN Notes App

NoteFlow is a full-stack MERN Notes Management Application designed to help users create, organize, search, and manage their notes efficiently through a clean and responsive dashboard interface. This project focuses on seamless frontend and backend integration using modern web technologies.

The application uses React.js for building an interactive user interface, Node.js and Express.js for creating RESTful APIs, and MongoDB with Mongoose for secure and efficient data storage. Users can create notes, view saved notes, search through their content, and manage their notes with a smooth and user-friendly experience.

## 🚀 Features

- Create and store notes dynamically
- View all notes from MongoDB database
- Search notes quickly
- Favourite and manage important notes
- Delete notes functionality
- Responsive and modern dashboard design
- REST API integration between frontend and backend
- Real-time data fetching using React state management

## 🛠️ Tech Stack

**Frontend:** React.js, JavaScript, HTML5, CSS3, Vite  
**Backend:** Node.js, Express.js, MongoDB, Mongoose  
**Tools:** Git, GitHub, VS Code, Thunder Client, MongoDB Atlas
